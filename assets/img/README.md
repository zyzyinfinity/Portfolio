# images

Drop image files here, then reference them from `assets/js/content.js`.

- **Project previews** — add `image: "assets/img/securescope.jpg"` to a project in
  `content.js`. It fades in on hover on desktop. Aim for ~800×600, optimised
  (JPG/WebP, under ~150 KB).

- **Social share card** — save a 1200×630 PNG as `assets/img/og.png`. It's already
  referenced by the Open Graph / Twitter tags in `index.html`.

- **Favicon** — replace `favicon.svg` in the project root with your own if you like.
